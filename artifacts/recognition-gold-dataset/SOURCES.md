# Source and evidence index

Canonical manifest, labels, source identities, complete captions, media, review packets, mappings and split membership remain private outside Git or in the ignored local evaluation directory. Public reports contain aggregate statistics. The preserved public source-history files and 207-row evidence CSV are not the runnable benchmark.

Private source packets preserve retrieval method/date, complete creator evidence, original media hash, timeline samples, independent review and exact reference/pin provenance. Public history must not be repurposed as newly hidden evidence. Fresh source identities are excluded from public CSVs and reports. See MEDIA_COLLECTION_REPORT.md, GROUND_TRUTH_PROVENANCE.md, DESCRIPTION_ABLATION_REPORT.md and PRIVATE_STORAGE_RECOVERY.md.
