# Gold recognition labeling guide

Record one line per distinct **real public post**. Use an opaque `case_id` and a `source_group_id` shared by confirmed reposts, near-identical edits, mirrors, and related source material. Keep acquisition details and observed caption/metadata in the manifest. Ground truth belongs only in the ignored private label file. A model prediction, autosave, or absence of a Wrong Place correction is not proof.

Use `VERIFIED_EXACT_SINGLE` for one established physical place and `VERIFIED_MULTI` only when the **complete depicted/relevant set** is established. Each place needs accepted names/aliases, a distinguishing geographic or provider identity, a provenance reference, and approximate segments when the video changes location. Mark places merely named in narration or an itinerary as `mentioned_only`; these do not count as depicted set members. A multi label needs at least two depicted places. Use `VERIFIED_REGION_ONLY` when geography is established but the physical place is not. Use `KNOWN_NEGATIVE` when no specific physical place can reliably be identified. Use `AMBIGUOUS` for unresolved competing exact locations and `UNVERIFIED` for evidence needing more research. Do not promote the last two into strict exact denominators.

For answer-bearing captions, descriptions, hashtags, tags, geography, and transcripts, record `answer_spans` as field + start/end offsets + category. Do not repeat the answer text in the span annotation. Check the actual text and visual overlays before enabling any masked view. `description_hidden` removes caption/description/hashtags and any annotated answer-bearing transcript, tag, or structured geography. `location_hidden` removes location tag and structured source geography. `visual_only` needs retained frames and no known answer-bearing title/text overlay; it removes all metadata and transcript. `text_only` excludes frames. An uncollected video does not support visual-only evaluation. Record misleading metadata as a research note and distinguish depicted location from sponsor, hometown, creator profile, comparison, and mentioned alternatives.

For every strict held-out label, an independent human reviewer must inspect the post and each proposed place, check a separately referenced source where possible, and record `review: {decision, reviewer, reviewed_at, independent:true}`. Mark `complete_set_established:true` only after all depicted places are adjudicated. The reviewer can choose `accept`, `reject`, `needs_more_research`, `region_only`, `ambiguous`, or `negative`. The local `npm run dataset:review -- --case …` command generates a read-only escaped HTML page with source evidence, proposal, provenance, and decisions; edit the private label file to persist the result. It never changes a label automatically.

Before freezing, check duplicate source IDs, mirrors, creator series, visually similar clips, same-name branches, source-group connections, and place-group connections. Split a connected group only when independent research proves it is unrelated. Historical cases with exposed outcomes remain development. Keep future held-out source records and labels local/private; inspect aggregate held-out results only at predefined milestones.
