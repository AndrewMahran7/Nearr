# Gold recognition labeling guide

Record one line per distinct **real public post**. Use an opaque `case_id` and a `source_group_id` shared by confirmed reposts, near-identical edits, mirrors, and related source material. Keep acquisition details and observed caption/metadata in the manifest. Ground truth belongs only in the ignored private label file. A model prediction, autosave, or absence of a Wrong Place correction is not proof.

Use `VERIFIED_EXACT_SINGLE` for one established physical place and `VERIFIED_MULTI` only when the **complete depicted/relevant set** is established. Each place needs accepted names/aliases, a distinguishing geographic or provider identity, a provenance reference, and approximate segments when the video changes location. Each depicted place in a ready exact label needs its own opaque `place_group_id`, repeated in `place_group_ids` for leakage checks. Mark places merely named in narration or an itinerary as `mentioned_only`; these do not count as depicted set members. A multi label needs at least two depicted places. Use `VERIFIED_REGION_ONLY` when geography is established but the physical place is not. Use `KNOWN_NEGATIVE` when no specific physical place can reliably be identified. Use `AMBIGUOUS` for unresolved competing exact locations and `UNVERIFIED` for evidence needing more research; these classes may keep private `proposed_places` but no accepted depicted `expected_places`. Do not promote them into strict exact denominators.

For answer-bearing captions, descriptions, hashtags, tags, geography, and transcripts, record `answer_spans` as field + start/end offsets + category where used. Do not repeat the answer text in the span annotation. Check actual text, compact handles, and visual overlays before enabling masked views. Record `mask_review` with reviewer/date, `answer_fields_checked:true`, and `permitted_media_derivative:true`; hash every retained frame in `evidence.frame_sha256`. `description_hidden` removes caption, description and hashtags; genuine speech and other permitted metadata remain. `location_hidden` removes the source location tag and structured geography. `visual_audio` contains frames and an actual spoken-audio transcript, with social metadata removed. `visual_only` removes all metadata and transcripts, while preserving legitimate text embedded in the original video pixels. Optional `visual_pixel_text_masked` requires separate reviewed masked images and hashes; it is never silently substituted for ordinary visual-only. `text_only` excludes frames. Strong scene-only exact cases need distinctive independently corroborated geometry without answer-bearing pixel text; ordinary visual-only eligibility alone does not establish this slice. An uncollected video does not support visual evaluation. Distinguish depicted location from sponsors, hometowns, creator profiles, comparisons and mentioned alternatives.

For every strict held-out exact label, record two distinct review passes: a collector/adjudicator and a fresh independent verification without reading or blindly trusting the proposed label. Separate agent contexts are allowed for this collection task; report them as agents, not humans. Record reviewer, date, source-specific observations, verification reference, evidence inspection, accepted place groups, prior identity exposure and agreement/disagreement. The adjudicating `review` records decision/reviewer/time/independence. Mark `complete_set_established:true` only after the entire depicted set is adjudicated. Every multi place needs aliases, approximate segments, coordinates with source/precision notes and a place group. The reviewer can accept, reject, request more research, or choose region-only/ambiguous/negative. A saved decision record does not automatically promote a candidate: reconcile identity, count, segment evidence and counterevidence first. A historical closed branch retains its original physical address and source date; never substitute a relocated branch.

Before freezing, check duplicate source IDs, mirrors, creator series, visually similar clips, same-name branches, source-group connections, and place-group connections. Split a connected group only when independent research proves it is unrelated. Historical cases with exposed outcomes remain development. Keep future held-out source records and labels local/private; inspect aggregate held-out results only at predefined milestones.
