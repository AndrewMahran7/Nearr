# Description and visual ablation

The dataset supports five deterministic views in the [materializer](../../scripts/gold-dataset/README.md), but current **eligible case counts** are: `full` 0, `description_hidden` 0, `location_hidden` 0, `visual_only` 0, `text_only` 38. The first four require permitted local visual evidence. A public post URL, browser playback, or retained caption excerpt is not an input video. `text_only` is useful for tool validation and future analysis; the cases are still candidates, not a baseline split with accepted full-post evidence.

Fifteen rows have one or more offset-marked answer-bearing fields. Six newly inspected YouTube Shorts were explicitly tagged `description_revealed`; the Instagram collection has additional partial caption/answer spans, often from excerpts. These are **discovery candidates**, far short of the 75–100 desired complete, independently reviewed description-revealed cases. On-screen place-name overlays must be reviewed separately; a masked caption is not a clean visual-only test when the answer is printed in the video.

Before enabling a masked variant, a human must review all answer-bearing caption, description, hashtag, location, tagged-account, geography, transcript, and overlay content. The mask review and media-rights record are explicit fields. The input receives only sanitized allowlisted evidence under an opaque ID; labels, source URLs, source paths, splits, and candidate caches are absent. Measure deltas only for **paired views of the same reviewed post**. No ablation delta is currently measurable.
