# Baseline scoring contract

The scorer accepts one observation per eligible case and evidence view. A missing observation fails the run; it is never silently scored as an incorrect result. Observation fields are `input_id`, `view`, `status` (`completed`, `review`, `failed`), `autonomous`, ordered `places`, ordered `candidates`, `multi_place_detected`, optional `geography`, and measured `elapsed_ms`/`cost_usd`. A review or failure with `autonomous:true` is invalid. Unknown costs stay null. Observations join to private labels only **after** inference through the opaque input ID.

Exact physical matching first uses equal provider-qualified IDs. Different IDs from the same provider do not match merely because the names do. Otherwise an accepted alias must match with required country/region/city and, when present, address or coordinates within the predefined radius. A same-name branch without comparable ID, address, or coordinates is not an exact match. Multi sets use maximum bipartite matching, so overlapping aliases cannot match one prediction to two places. Mentioned-only places are excluded from the depicted expected set.

**Primary metric:** correct autonomous resolution = completed autonomous exact-correct single/set outputs divided by all reviewed, exact-labeled cases flagged as reasonably expected to yield a place/set. The expectation flag must be frozen before observing benchmark results. A case sent to review stays in this denominator and does not increase the numerator. Autonomous precision = exact-correct autonomous outputs divided by all adjudicable autonomous **place** outputs (including unsupported exact outputs on negative and region-only cases). A completed no-place abstention is scored under negative abstention, not as a wrong place output. Autonomous outputs on ambiguous/unverified cases are reported separately because their exact correctness cannot be adjudicated. A zero denominator yields `null`, never 100%.

Single metrics: exact top-1, candidate recall at 1/3/5, correct autonomous, wrong country and region. Multi metrics: detected multi, per-place precision/recall/F1, exact-set accuracy, extra places, missed places, correct autonomous. Negative metrics: correct abstention and unsupported exact. A failed job is not a correct abstention. Region-only metrics: correct geography and unsupported exact identity. Wrong confident counts incorrect autonomous exact outputs and an explicitly observed wrong-confident cache result, including one later routed to review/failure. Cost per correct autonomous result is null when cost coverage is incomplete or there are no correct autonomous outputs. Timings include measured p50/p75/p90/p95 for all submissions, correct usable results, and correct autonomous results; absent timing remains absent. Report evidence-view deltas only on paired case IDs with both views and the same frozen label and group; do not count distinct masks of one post as independent examples.

The tool's aggregate output is suitable for a normal report. Per-case rows contain private truth and are written under `.local/recognition-gold-dataset/`. A held-out score requires a checked seal and explicit `--explicit-heldout`; run its first baseline once and keep future per-case result access restricted.
