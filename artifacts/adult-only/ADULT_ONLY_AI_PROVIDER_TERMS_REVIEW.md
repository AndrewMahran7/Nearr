# Adult-only AI-provider and Apple review (retrieved 2026-10-18)

Primary sources reviewed: [Gemini API Terms](https://ai.google.dev/gemini-api/terms), [Google Cloud Service Terms](https://cloud.google.com/terms/service-terms) (current generative-AI age provision in §17(d)), [Apple App Review Guidelines](https://developer.apple.com/app-store/review/guidelines/) (§5.1.2(i)), [Apple age-rating help](https://developer.apple.com/help/app-store-connect/manage-app-information/set-an-app-age-rating), [Apple App Privacy](https://developer.apple.com/app-store/app-privacy-details/), and [FTC COPPA guidance](https://www.ftc.gov/business-guidance/resources/complying-coppa-frequently-asked-questions). The live worker uses the Gemini Developer API for model calls; the Cloud terms are relevant context but are not a substitute for identifying the actual contracted API.

Google's applicable generative-AI restriction addresses apps directed at or likely to be accessed by under-18 individuals. Nearr's old under-13-capable positioning cannot be cured by a metadata change alone. The proposed 18+ restriction, server-side account decision, old-client ingress guard, queue/worker checks, revised policy/Terms and eventual Store age override materially change the product's intended audience and access pattern. **However**, self-declaration is not independent age proof, account recreation is possible, existing 1.4/Production backend remains unchanged, and the Dev Edge/worker is not deployed. There is no support yet for a conclusion that Nearr is no longer “likely to be accessed” by minors. Qualified counsel or Google contractual clarification should answer whether this actual control set is adequate for the API Nearr uses; founder approval cannot waive a provider condition.

Apple requires explicit permission before sharing personal data with a third-party AI service under §5.1.2(i). The copied privacy-corrected client contains a per-share AI permission prompt; the backend does not yet durably prove consent, and the old 1.4 client contract has not been qualified for that requirement. Privacy-policy acceptance, age declaration, AI-sharing permission and App Tracking Transparency are separate decisions. Do not claim permission coverage or change ASC privacy answers until the data-flow and old-client evidence is complete.

COPPA concerns children under 13; the new product decision excludes all minors. This draft does not establish compliance while the currently public version and backend remain available. Do not market Nearr to minors, use children in screenshots/marketing, or claim an App Store rating verifies identity. If Nearr has Kids-category history, verify implications in ASC before acting.
