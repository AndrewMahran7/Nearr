- `process-share-link` returns the existing HTTP-200 transport envelope with `paused=true`, an explicit temporary-unavailable reason, zero candidates, no place, no save and `manual_fallback`. Actual historical parser/decision-block tests confirm this response exits before fallback and autosave. AI-note enrichment inserts are skipped before INSERT/ON CONFLICT, because otherwise a normal video-source manual save would be rolled back by its optional enqueue trigger.
