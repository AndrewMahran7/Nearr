# Historical recognition source inventory

`historical_social_candidates.jsonl` contains 105 distinct social-post **source references** gathered from previously retained Nearr research, not 105 benchmark-ready cases. Every row is `state: candidate`, `exposure: historical_outcomes_already_exposed`, `retrieval_date: null`, and `public_access_status: public_access_unconfirmed`. The original work recorded these as public or authorized fixtures, but this audit did not freshly retrieve each post or verify that it is still public. No heldout test case may be drawn from them.

The frozen v2 input set has 118 entries: 88 social posts, 28 Wikimedia Commons media controls, and two constructed composites. Seventeen other distinct social references came from retained founder metadata, regression, and tutorial fixtures, giving 105 historical social candidates: 95 Instagram, five YouTube, two TikTok, two Facebook, and one Snapchat. The Commons items are useful controls, but they are not social posts and are not included here. `legacy_source_mapping.jsonl` links opaque IDs to old fixture IDs for audit only; it must never be passed to recognition or used as ground truth.

Only 27 candidates have retained caption/description text. None has a permitted retained frame in this inventory. Accordingly, only those 27 expose a possible `text_only` view; `full`, `description_hidden`, `location_hidden`, and `visual_only` are false for every row. Text snapshots are copied verbatim from retained extraction records, including any earlier extraction artefacts. Answer spans and visual overlays have not been reviewed. The exact case/source IDs derive from normalized platform content IDs, not from an old URL-canonicalization or model-output grouping.

`scripts/recognition-gold/collect-existing-candidates.mjs` regenerates the committed source inventory and a separate **unreviewed** private label template. It makes no network, model, paid, or database call. The adjudicated private file is separate and will not be overwritten by the source collector. The private adjudication notes themselves are gitignored. Official or public corroboration links and detailed review reasons are inside that private draft. The inventory records source-file hashes and aggregate counts for reproducibility.
