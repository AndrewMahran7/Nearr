# Founder/manual frame arm

No exact founder screenshot sets were present when this experiment was created, so F3 is unavailable.

To add one without changing inference code, place Andrew's original `.jpg`, `.jpeg`, `.png`, or `.webp` screenshots in `manual-frames/<case-id>/`. Prefix a filename with its timestamp in seconds when known (for example `12.4-sign.jpg`). Files are sorted lexically and sent unchanged. Do not place labels or answer text in this tree.
