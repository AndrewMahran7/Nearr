# Recognition Pareto frontier

The selected implementation is **repaired Development safety + identical-evidence batched frame hashing + bounded per-execution Places queries + stale-claim fencing**. This is the strongest locally qualified implementation, not a demonstrated improvement in population-level correct autonomous recognition. The primary improvement target remains unproven.

No complete end-to-end Pareto frontier can be estimated from this corpus. There are no fresh paired provider runs, no genuinely unseen recognition holdout, no real verified multi-place videos, and no complete billed-cost ledger for the historical cohort. An unmeasured quantity is never assigned zero to manufacture dominance.

| Comparable experiment boundary | Alternatives | Evidence | Decision |
|---|---|---|---|
| Frame preparation, identical bytes | Legacy per-frame hash / batched hash | 24 sources, 28 paired runs, all evidence equal; held-out n4 p90 7.076 to 5.079 seconds | Batched hash selected; calibration p95 regression retained |
| True one-decode frame prototype | Legacy / single-decode | 3/16 development failures; slower successful-source tail | Reject |
| Synthetic scheduling, fixed 1s ASR delay | Serial / batch / parallel / batch+parallel | Three repetitions per arm; identical bytes and synthetic transcript | Batch+parallel fastest locally; parallel remains off pending concurrent resource qualification |
| Stored Places workload, fixed 5ms provider delay | Serial / memoized / bounded | 32 attempts, five repeats, 40 calls per workload in every arm, ordered candidates equal | Bounded selected for scheduling; no observed request or dollar saving |
| Retained post-deep source policy | Repaired / winner | 31 cases, 15 exact-label eligible; ordinary results all review | Policy parity only; cannot test media, query concurrency, routing, or model quality |
| Visual reference retrieval | EigenPlaces global / country-filtered | Four cross-source locality queries from two groups: top1 2/4, top3 4/4 for both | Eval only; no exact identity qualification |
| Geometric overlap | DISK + LightGlue shortlist | 11/14 positive matches, 3/22 wrong-locality matches accepted | Reject as identity verifier |

The latency engineering target of at least 20% p90 reduction is met only for the small held-out **frame stage** (28.2%). It is not established for time to a correct result. Calibration p95 rises from 9.523 to 10.248 seconds. No strategy demonstrates the 10% cost-per-correct-autonomous target. Batched hashing sends identical images to the model, so it cannot claim image-token savings.

Safety repairs are baseline prerequisites, not accuracy wins against a deliberately weaker Production comparator. Conservative abstention is never scored as correct autonomy. The old Production Sol/no-Sol timings are selection-biased and cannot justify disabling Sol.

Stopping condition: further useful accuracy comparisons require independently adjudicated source evidence, real multi-place sets, proper-noun audio transcripts, rights-cleared reference views, and a bounded paid-provider budget. Additional threshold tuning on the present exposed corpus would not resolve those limits.
