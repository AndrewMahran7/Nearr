# ASR routing and preparation experiment

The existing platform-caption preference is preserved. Where captions are absent, the existing audio extraction and transcription provider still supply timestamped segments before recognition. No caption-presence heuristic, music guess or silent transcription failure is promoted into exact-place identity evidence.

Implemented: optional concurrent ASR/frame preparation with a complete evidence join and cancellation. The offline benchmark uses real generated PCM extraction plus a fixed simulated 1,000ms ASR wait. Across four arms × three repetitions, all audio hashes, transcript payloads and frame evidence match (12/12). Serial baseline p50 is2.397s; parallel only1.317s; batchhash+parallel1.096s. This is a **scheduling control**, not a Whisper/provider benchmark, and the transcript is explicitly synthetic. See [MEDIA_PIPELINE_BENCHMARK.md](MEDIA_PIPELINE_BENCHMARK.md).

No paid ASR request was made. A paired place-name/multilingual ground-truth audio set with explicit call budget was not available in this local execution. Therefore Whisper vs GPT-Transcribe word/name accuracy, actual ASR latency, contribution to exact autonomous resolution, and cost per correct result are **unmeasured**. The pipeline continues using the configured existing provider/model; no replacement is claimed to win.

The current OpenAI adapter requests `verbose_json` and consumes timestamped segments. A migration must qualify the supported output format, language reporting, actual segment timestamps, errors/timeouts and noun recall. A text-only response with fabricated zero-length scene timestamps is not equivalent evidence for multi-place grouping. Current official documentation gives Whisper retirement as February26,2027 and lists GPT-Transcribe as a replacement. That replacement uses JSON (with an optional `languages[]` hint), so blindly changing the model environment variable while retaining the unconditional `verbose_json` request is not a qualified migration. [Official deprecations](https://developers.openai.com/api/docs/deprecations).

Routing decisions still safe without a new model benchmark: reuse usable platform subtitles; avoid calls when a provider already knows no audio exists; preserve a failed/unavailable status rather than claiming no speech. Caption availability alone does not prove spoken venue names are redundant. Energy/VAD is not a proper-noun accuracy metric and can suppress a quiet, important name; music and multilingual clips need adjudicated controls before skipping ASR.

Next bounded provider experiment:30 properly labeled audio samples totaling at most30minutes per provider, two arms, source/place grouped, measuring venue/street/city proper nouns, transcript-induced decision changes, multi-place alignment, wall time and actual billed audio duration. Expected first-pass cost is at most$1; request a **$2 hard ceiling including retries**, reprice against supported models immediately before execution, and stop at the ledger cap. Use one attempt per arm initially and no automatic retries. Ground-truth audio and approval are required before the first paid request. This task spent **$0.00** on ASR.
