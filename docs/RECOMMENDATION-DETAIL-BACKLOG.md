# Also-nearby recommendation detail redesign

Status: **BACKLOG / DESIGN APPROVED**

This follow-up is intentionally not part of the validated Product UI production release. The current physically tested recommendation-detail UI ships unchanged.

Approved direction for a later implementation:

- polished dark bottom sheet with an “Also nearby” contextual header;
- large rounded hero photo and stronger place-name hierarchy;
- category, distance, and clean address treatment;
- dominant orange “Save place” action and secondary “Directions” action;
- explicit save remains required;
- remove “Not saved until…” implementation copy;
- optional subtle “Not this place?” correction affordance.
